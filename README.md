# Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game built using python

## Features

- User vs computer
- Totally random computer choices
- Win/Loose/Draw logic
- Beginner Python project

## Technologies used

- Python

## How to Rum

'''bash
python RPS_GAME.py
'''
